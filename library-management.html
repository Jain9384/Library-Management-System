🚀 Getting Started with Library Management System

To use the full Library Management System with CRUD operations, please follow these steps:

Step 1: Start the JSON Server (Backend)

npx json-server --watch db.json --port 3000

Step 2: Start the Angular Development Server

ng serve --port 4200

Step 3: Access the Management System

Once both servers are running, the Library Management System will be available at:

http://localhost:4200

✨ Features Available:

  • 📖 View all books in the library
  • ➕ Add new books to the collection
  • ✏️ Edit existing book information
  • 🗑️ Delete books from the collection
  • 🔍 Search functionality
